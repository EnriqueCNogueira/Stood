# Stood

O Stood é um site para organizar estudos: cada Stood reúne em pastas os vídeos, notas, desenhos, imagens e PDFs de um assunto, abertos lado a lado num quadro, e pode ser versionado no GitHub.

## Linguagem

### Identidade

**Usuário**:
A pessoa que usa o Stood, identificada por um e-mail único e dona de tudo o que cria.
_Evitar_: Conta, perfil, cliente

**Conta**:
Uma forma de entrar ligada a um Usuário: Google, GitHub ou e-mail e senha. Um Usuário pode ter várias Contas.
_Evitar_: Login, provedor, credencial

### Stood

**Stood**:
A unidade de estudo do Usuário: um conjunto de Pastas e Arquivos sobre um assunto. O plural é Stoods.
_Evitar_: Estudo, repositório, projeto

**Quadro**:
A tela que abre um Stood, em que os Arquivos aparecem em Janelas. 
_Evitar_: Board, canvas, workspace

**Janela**:
Um Arquivo aberto no Quadro, que o Usuário move, redimensiona e fecha.
_Evitar_: Painel, aba

**Pasta**:
Um agrupamento de Arquivos e de outras Pastas dentro de um Stood.
_Evitar_: Diretório

**Arquivo**:
Um item de conteúdo de um Stood, de um dos tipos Nota, Desenho, Imagem, PDF ou Vídeo.
_Evitar_: Documento, item, anexo

### Tipos de Arquivo

**Nota**:
Um Arquivo de texto em markdown.
_Evitar_: Anotação, texto, md

**Desenho**:
Um Arquivo de desenho livre feito no Excalidraw.
_Evitar_: Excalidraw, rabisco

**Imagem**:
Um Arquivo de foto ou print, que pode ser importado ou capturado de um Vídeo.
_Evitar_: Foto, print, captura

**PDF**:
Um Arquivo PDF, como apostila, livro, artigo ou slides da aula.
_Evitar_: Documento, slides

**Vídeo**:
Um Arquivo que aponta para um vídeo do YouTube.
_Evitar_: Link, aula, YouTube

### GitHub

**Repositório**:
Um repositório do GitHub em que o Usuário versiona um Stood. Não é um Stood.
_Evitar_: Repo
