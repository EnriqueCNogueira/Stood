# Stood

O Stood é um site para organizar estudos: cada estudo é um quadro com janelas de vídeo, nota, desenho, imagem, PDF e slides, e os arquivos ficam em repositórios que podem ser versionados no GitHub.

## Linguagem

### Identidade

**Usuário**:
A pessoa que usa o Stood, identificada por um e-mail único e dona de tudo o que cria.
_Evitar_: Conta, perfil, cliente

**Conta**:
Uma forma de entrar ligada a um Usuário: Google, GitHub ou e-mail e senha. Um Usuário pode ter várias Contas.
_Evitar_: Login, provedor, credencial
